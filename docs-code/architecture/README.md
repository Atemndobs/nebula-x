## How to Use

- **For new developers**: Start with the [Architecture Overview](./overview.md) and [Technical Stack](./tech-stack.md) documents.
- **For architectural decisions**: Review the [Architecture Decision Records (ADRs)](./decisions/README.md) to understand why certain technologies or patterns were chosen.
- **To propose changes**: Create a new ADR following the template in [template.md](./decisions/template.md).

## Contributing

When making significant architectural decisions, please create a new ADR to document the decision-making process.
