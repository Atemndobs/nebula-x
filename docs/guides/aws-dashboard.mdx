# AWS Usage Dashboard Guide

## Overview
The AWS Usage Dashboard provides a comprehensive view of your AWS resources, including EC2 instances, S3 buckets, IAM configurations, and DynamoDB tables. This guide covers the dashboard's features, testing, and how to use them effectively.

## Recent Changes (May 2025)

- Added support for multiple AWS accounts

## Getting Started

### Prerequisites
- Access to the Nebula Logix platform
- AWS account with appropriate permissions
- Latest version of a modern web browser

### Accessing the Dashboard
1. Log in to your Nebula Logix account
2. Navigate to the Dashboard section
3. Select "AWS Usage" from the sidebar

## Dashboard Features

### Overview Section
- **Resource Summary**: Quick view of all AWS resources
- **Cost Overview**: Current month's spending and budget utilization
- **Alerts & Notifications**: Critical issues requiring attention

### EC2 Instances
- **Instance List**: View all EC2 instances with status and details
- **Resource Utilization**: CPU, memory, and network metrics
- **Instance Actions**: Start, stop, or terminate instances

### S3 Storage
- **Bucket Overview**: List of all S3 buckets with storage metrics
- **Storage Distribution**: Visual breakdown of storage usage
- **Access Logs**: View and manage bucket access logs

### IAM Management
- **Users & Roles**: Manage IAM users and their permissions
- **Access Keys**: View and rotate access keys
- **Policies**: Manage IAM policies and permissions

### DynamoDB
- **Table Metrics**: View read/write capacity and storage
- **Item Count**: Monitor the number of items in each table
- **Performance Metrics**: Track request latency and throttling

## Testing the Dashboard

### Running Tests

#### Prerequisites
- Node.js 16+
- Playwright installed (`npx playwright install`)
- AWS credentials configured

#### Running Tests

Run all tests:
```bash
npx playwright test
```

Run AWS dashboard tests specifically:
```bash
npx playwright test tests/e2e/aws-dashboard.spec.ts
```

Run with UI mode for debugging:
```bash
npx playwright test --ui
```

### Test Coverage

- **Authentication**: Verify login and access control
- **Data Loading**: Test data fetching and display
- **Interactions**: Test user interactions with charts and tables
- **Responsiveness**: Verify UI on different screen sizes
- **Error Handling**: Test error states and recovery

## Best Practices

### Cost Optimization
- Use the cost overview to identify underutilized resources
- Set up budget alerts in the settings
- Regularly review and clean up unused resources

### Testing Best Practices
- Write atomic, independent tests
- Use data-testid attributes for reliable element selection
- Mock external dependencies in unit tests
- Run tests in CI/CD pipeline
- Update visual baselines when UI changes are intentional

### Security
- Follow the principle of least privilege for IAM users
- Regularly rotate access keys
- Enable MFA for all IAM users

### Performance
- Monitor performance metrics to identify bottlenecks
- Set up CloudWatch alarms for critical metrics
- Use the dashboard's filtering and sorting features to focus on specific resources

## Troubleshooting

### Common Issues
- **Missing Data**: Ensure proper IAM permissions are configured
- **Loading Issues**: Check your internet connection and try refreshing the page
- **Permission Errors**: Verify that your user has the necessary permissions
