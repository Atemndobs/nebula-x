# Admin User Flows

## 1. Authentication & Dashboard Access

```mermaid
sequenceDiagram
    participant U as Admin User
    participant FE as Frontend
    participant BE as Backend
    participant AWS as AWS Services
    
    U->>FE: 1. Visits landing page
    U->>FE: 2. Navigates to /login
    U->>FE: 3. Enters admin credentials
    FE->>BE: 4. POST /api/auth/login
    BE-->>FE: 5. JWT Token + User Data
    FE->>FE: 6. Store token & user role
    FE->>U: 7. Redirect to /dashboard
    U->>FE: 8. Views dashboard
    FE->>BE: 9. GET /api/aws/usage (with JWT)
    BE->>AWS: 10. Request AWS usage data
    AWS-->>BE: 11. Return AWS metrics
    BE-->>FE: 12. Return formatted data
    FE->>U: 13. Display AWS usage dashboard
```

### Key Components:

1. **Frontend (React)**
   - Handles user interface and interactions
   - Manages authentication state
   - Displays AWS usage data in dashboard

2. **Backend (Node.js/Express)**
   - Validates JWT tokens
   - Enforces role-based access control
   - Fetches and processes AWS data

3. **AWS Services**
   - CloudWatch for metrics and monitoring
   - IAM for secure access control
   - Other AWS services as needed

### Security Notes:
- All API requests require valid JWT
- Admin role verification on sensitive endpoints
- Rate limiting and request validation
- AWS credentials securely stored and managed
